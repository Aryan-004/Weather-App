# Weather App 🌤️

A simple weather application built using HTML, CSS and JavaScript.

## Features

- Search weather by city
- Displays current temperature
- Displays humidity
- Displays wind speed
- Dynamic weather icons
- Handles invalid city names

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API

## What I Learned

- DOM manipulation
- Event listeners
- Fetch API
- Promises
- Async/Await
- Working with APIs
- Handling API responses
